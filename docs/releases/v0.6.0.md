# Release v0.6.0

**Date:** 2026-08-16  
**Previous release:** [v0.5.0](https://github.com/ShamindaKanchana/Expense_tracker/releases/tag/v0.5.0) (tag only; release notes were not published)  
**Status:** **Current**  
**GitHub release:** [v0.6.0](https://github.com/ShamindaKanchana/Expense_tracker/releases/tag/v0.6.0)

## Summary vs previous release

This release adds the **monthly expense list** with month/year filtering and pagination, merges the **Travel** category into **Transport**, shows the **app version in the login footer**, and **localizes + themes the monthly report** (EN/SI/TA) with category accent colors.

| Area | v0.5.0 | v0.6.0 |
|------|--------|--------|
| Monthly expenses | Dashboard chart only | **Monthly list view** with year/month filter + paginated `GET /api/expenses/list` |
| Categories | 10 (incl. `Travel`) | **9** — `Travel` merged into `Transport` |
| Login footer | Static credit line | Shows **app version** (e.g. `v0.6.0`) from `package.json` |
| Monthly report UI | English, plain | **Localized** (EN/SI/TA) + theme-aware **category accent colors** |

## Features

### Monthly expense list

- New private endpoint **`GET /api/expenses/list`** — paginated expense list with optional `year` + `month` filters
- Frontend monthly report view: month/year selection, per-category rows tinted with theme-aware colors, chart segments re-colored per category
- SRS: [monthly-expense-list.md](../srs/monthly-expense-list.md)

### Category cleanup

- `Travel` removed from the category ENUM (`backend/models/Expense.js`, migration, `reset-db.js`) — merged into `Transport`
- Frontend `CATEGORY_KEYS` and i18n updated to match

### Auth / UX

- Login footer now shows the app version (`© 2026 Expense Tracker v0.6.0 …`) via `frontend/src/config.js`

### Monthly report localization & theming

- Monthly report translated across `en`/`si`/`ta`
- Language switcher styling polish
- Theme-aware category color palette for table rows and charts (light/dark)

## Bug fixes / UX

- Version footer and report labels correctly localized in all three languages
- Consistent category accent colors across rows, charts, and detail swatches in both themes

- New endpoint `GET /api/expenses/list` ships with the backend
- **Frontend only** for the version footer and localization — no new env vars
- Frontend version bumped to `0.6.0`
